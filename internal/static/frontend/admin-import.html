💡 Tipps zum Import

  • Laden Sie zuerst die Vorlage herunter, um das erwartete Format zu sehen
  • Die Name-Spalte ist erforderlich
  • Größen werden automatisch erkannt: klein/small, mittel/medium, groß/large
  • Farben müssen den konfigurierten Farbkategorien entsprechen (z.B. Grün, Orange, Blau)
  • Verfügbarkeit wird automatisch erkannt: ja/yes/true/1 = verfügbar
  • TEO-Exporte können direkt importiert werden
